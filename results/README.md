# Результати вимірювань

Актуальні файли отримано на даних RTPTorrent, зведених за комітами, з
перенавчанням моделей лише на навчальній частині.

| Файл | Що містить |
|---|---|
| `import_rtptorrent.txt` | звіт імпорту датасету |
| `train_real.txt` | метрики навчання моделей |
| `experiments_final.txt` | економія часу і частка виявлених дефектів |
| `stand_evidence.txt` | підсумок стенда GitLab CE: обсяг даних, моделі, вибірковий прогін |
| `apfd_final.txt` | APFD: випадковий, наявний порядок, DFE, запропонований метод |
| `active_window_tuning.txt` | підбір розміру вікна живих тестів |
| `jobs_*.txt` | переліки прогонів, на яких зроблено вимірювання |

Проміжні файли з ранніх прогонів видалено навмисно: вони містили числа,
отримані до виправлення двох витоків даних (агрегати тестів за всю історію
та складання-побратими того самого коміту як окремі конвеєри), тому
використовувати їх у записці не можна.
